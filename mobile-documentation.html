Getting Started with the Acme Mobile App

A mobile-app onboarding guide for users setting up the application for the first time.

What you’ll need

  • An iOS or Android device
  • An active Acme account
  • An internet connection

1. Install the app

Open the App Store or Google Play, search for Acme, and select Install.

2. Sign in

Open the app and enter the email address and password associated with your account.

3. Allow notifications

Allow notifications if you want updates about account activity and workflow changes.

4. Complete setup

Follow the on-screen prompts. You can change preferences later from Profile → Preferences.

Troubleshooting

The app is not syncing: Check your connection and make sure the app is up to date.
