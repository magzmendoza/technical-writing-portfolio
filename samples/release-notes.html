Acme Platform 4.8 — Release Notes

A concise release-notes sample that communicates what changed, why it matters, and what users need to know.

What’s new

Faster dashboard loading

Dashboard pages now load faster for workspaces with large datasets.

Bulk approval actions

Approvers can select multiple requests and approve or reject them in one action.

Improvements

  • Improved request-list search suggestions.
  • Added clearer status labels.
  • Improved mobile approval details.

Bug fixes

  • Fixed duplicate rows in exported reports.
  • Fixed date formatting in some regional settings.

Action required

No action is required. Changes are available automatically after the update.
