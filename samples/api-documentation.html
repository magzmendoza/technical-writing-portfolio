Acme REST API: Getting Started

A developer-focused API sample covering authentication, a first request, responses, and common errors.

Before you begin

Create an API key and make sure you have access to a terminal or API client such as Postman.

Authentication

Send your API key in the Authorization header using Bearer authentication.

Authorization: Bearer YOUR_API_KEY

Get a list of users

GET /v1/users

curl https://api.example.com/v1/users \
  -H "Authorization: Bearer YOUR_API_KEY"

Successful response

{
  "data": [{"id": "usr_123", "name": "Alex"}]
}

Common errors

  • 401 Unauthorized: Missing or invalid API key.
  • 403 Forbidden: Insufficient permissions.
  • 429 Too Many Requests: Rate limit exceeded.
