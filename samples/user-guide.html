Getting Started With a New Feature

A sample product user guide.

What this feature does

This feature helps users complete a common task from one place, reducing the number of steps needed.

When to use it

Use the feature when you need to manage the task repeatedly or want a single view of its current status.

Get started

  1. Open the product.
  2. Select the feature from the main navigation.
  3. Choose an item to manage.
  4. Review the result and save your changes.

Tips

Use descriptive names and review changes before saving. If your workspace has multiple users, confirm that you have the required permissions.
