Smart Approvals: Product Documentation

A structured product-documentation sample designed to explain a feature, guide users through a workflow, and provide troubleshooting help.

What is Smart Approvals?

Smart Approvals helps teams automatically route requests to the appropriate reviewer based on department, project, or request amount.

Key benefits

  • Reduce manual approval routing
  • Apply consistent approval rules
  • Improve request visibility

Configure an approval rule

  1. Open Settings → Approvals.
  2. Select New rule.
  3. Choose a trigger condition.
  4. Select reviewers.
  5. Click Save.

Verify

Submit a test request that matches the condition and confirm that it reaches the expected reviewer.
